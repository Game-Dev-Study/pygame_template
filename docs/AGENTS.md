# Documentation Instructions

`docs/`는 코드 구조와 중요한 실행 흐름을 코드와 함께 관리한다.

## Documents

- `architecture.md`: 모듈 책임과 의존 방향
- `class_hierarchy.md`: 주요 기반 클래스와 상속 구조
- `ui_flow.md`: 프레임 처리, 렌더링, UI 입력 흐름
- `feature_flow.md`: 게임별 복잡한 기능의 입력, 판정, 실행 흐름

## Rules

- 현재 코드와 확인된 규칙만 기록하고 아직 없는 기능은 확장 예시로 명시한다.
- 구조나 책임이 바뀐 변경에서는 관련 문서를 같은 작업에서 갱신한다.
- 다이어그램의 이름은 실제 package와 class 이름을 사용한다.
- 텍스트 파일은 UTF-8로 저장한다.
