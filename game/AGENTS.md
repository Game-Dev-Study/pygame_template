# Game Instructions

`game/`은 게임 규칙, 정의 객체, 런타임 상태, 여러 화면에 걸친 관리자와 독립 로직의 확장 지점이다.

## Rules

- 정의 데이터와 플레이 중 변하는 런타임 상태를 구분한다.
- 게임 규칙, 상태 관리자, 절차적 생성, 경로, 가시성, 시간 진행처럼 화면에 종속되지 않는 책임을 둔다.
- `game/`은 `scenes/`와 `ui/`를 import하지 않는다.
- 여러 상태를 함께 바꾸는 작업은 상태 소유 객체의 메서드로 캡슐화한다.
- 미리보기와 실제 적용은 같은 계산 함수를 사용한다.
- 무작위 계산은 난수 객체를 주입받을 수 있게 설계한다.
- 객체 identity와 값 동등성 중 무엇이 중요한지 명확히 하고 복사 정책을 일관되게 유지한다.
- 외부에 필요한 타입만 `game/__init__.py`에서 공개한다.
- 코드가 많아진 뒤에만 필요에 따라 `models/`, `states/`, `managers/`, `systems/` 같은 하위 package로 분리한다.
